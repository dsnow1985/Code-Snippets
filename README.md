# Code-Snippets

A collection of useful code snippets and scripts for customizing, fixing, and troubleshooting WordPress and WooCommerce sites.

## Overview

This repository can be used as a standalone plugin. The main loader file (`ds-snippets.php`) automatically scans the `snippets/` folder and creates a control panel under **Settings > DS Snippets** in the WordPress dashboard, allowing you to toggle individual snippets on and off.
